# APK Android JASG Automotriz

Proyecto Android nativo que empaqueta los módulos HTML actuales en un WebView local. Los datos continúan guardándose en el almacenamiento local del dispositivo.

## Compilar

1. Instalar Android Studio con Android SDK 35.
2. Abrir esta carpeta `android` como proyecto.
3. Esperar la sincronización de Gradle.
4. Ejecutar `Build > Build APK(s)`.

El APK de prueba quedará en `app/build/outputs/apk/debug/app-debug.apk`.
